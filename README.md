---------------------------------------------------------------------------------------SHOP_CODE------------------------------------------------------------

Простой, но многофункциональный код кассы самообслуживания магазина, с возможностью создания своих собственных аккаунтов для покупателей. 
Имеет отдельный админ аккаунт с многофункциональной админ-панелью, в которой можно управлять ассортиментом, количеством товаров, а также посмотреть статистику покупки товаров. А ещё админ-панель защищена шифрованием пароля администратора.
В меню пользователя имеется корзина товаров, виртуальный счет, красивый вывод чека, просмотр меню и последних заказов.
Есть возможность создания, удаления и изменения учетных записей.
